这些数字是怎么算的？

本机用量

读取 Claude Code、Codex CLI、Grok Build 的会话记录。时间范围按本地自然日（含今天）计算，对比紧邻的上一段等长时间；今天尚未结束。

输入、输出与缓存

总 Tokens = 输入 + 输出。缓存读取和缓存写入已包含在输入中，推理 Tokens 已包含在输出中，不能再次累加。缓存读取占比 = 缓存读取 / 全部输入。

额度与预测

官方账号额度独立采样。平均速度按整个窗口已经过去的时间计算，包括休息时间。预测是使用节奏的参考；最近速度、最快耗尽时间和折算容量并非官方承诺。超过 15 分钟的采样标为过期，重置后需等待新采样确认。

费用与导出

优先使用日志自报费用，其余按项目内单价表估算。未知模型不会被当作免费。CSV 导出当前时间、工具和搜索筛选下的全部匹配明细，不受分页限制。
