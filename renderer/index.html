用量明细

每一行是一次 API 请求：用了多少 Token、占了多少额度、谁发的、型号对不对。点开看详情

请求型号 vs 返回型号

Claude Code 和 Grok Build 的会话文件同时记下了「要的型号」和「上游回的型号」，两者对不上就标型号不一致。

响应特征

Anthropic 官方的响应 ID 是 msg_ 加 24 位、每次都带 req_ 开头的请求 ID。号称 Claude、ID 却是 OpenAI 或 UUID 等格式，说明请求被别家接口转换过，标响应存疑。

无法核验

Codex 的会话文件不记录上游返回的型号；旧版 Claude Code 不记录请求的型号。这些只核对了响应格式。

额度占用

这次请求的 Token ÷ 它所在额度窗口折算出的整窗容量，是估算；只算走官方账号、而且窗口能折算出容量的请求。

局限

只读本机记录，不额外发请求、不花额度。中转站可以把型号名和 ID 都伪造成官方的样子，「一致」只说明没露馅，「不一致」和「存疑」才是实打实的证据。

设置

外观、官方账号、额度提醒和本地数据都在这里。

官方账号

每家可以登记多个账号，并聚合成一个账号池；列表显示额度、顺位和用完提醒。按住左边的把手拖动可以调整使用顺序，达到上限才提示切到下一个，TokenPulse 不会改写 CLI 登录。点铅笔可以给账号起名字，点「添加账号」可继续添加。

CLI 自己的登录只读取不复制，也不会被续期（用「本机 CLI 已登录的账号」添加的就是这种，不保存凭据）；在这里登录的账号，凭据（含续期用的 refresh token）保存在本机 official-accounts.json，仅用于查询额度，不会上传，并在过期前自动续期。

数据位置

用量账本、额度采样历史和设置都只保存在本机 ~/.tokenpulse/，不会上传。删掉用量账本会从头重扫、不丢数据；额度采样历史官方不提供，删了就找不回来。

tokens.ci 自动上传

按你设的间隔，由 TokenPulse 运行 tokens.ci 的官方工具，把用量上传到 tokens.ci 排行榜。上传的数据由那个工具自己扫描，只有 Token 数、型号和时间；TokenPulse 自己的账本仍然只在本机。

API Key 余额监控

DeepSeek 按量付费，没有订阅额度。填一个 DeepSeek 开放平台的 API Key，TokenPulse 每 10 分钟查一次余额，低于你设的数时提醒。有几个账号可以填几个，每个账号在额度详情里各有一页。Key 只保存在这台电脑上，只用来查余额，查余额不花钱。

自己买的第三方中转站 Key 也可以监控：填站点地址和 Key，能看到余额、Key 的额度和限速窗口、每天的用量。支持 sub2api 和 new-api / one-api 搭的站。Key 只发给你填的那个站点。

供应商配置备份

TokenPulse 每次改动 Claude / Codex / Grok 的配置文件前都会先让你确认，并自动留一份备份；接管前的原件也单独保存。可以在这里一键还原，或打开只读保护。

从 CC Switch 导入

只读 CC Switch 的本地库，补上 TokenPulse 自己没有的那部分：CLI 已经清掉的老会话、OpenCode 这类不扫描的工具。同一天同一个工具两边都有时只算 TokenPulse 自己的，不会重复。走 CC Switch 代理的请求还会用它记下的上游返回型号来核验。

统计口径

本机用量

读取 Claude Code、Codex CLI、Grok Build 的会话记录，并按天补上 CC Switch 里有、本机会话已经没有的记录。时间范围按本地自然日（含今天）计算，对比紧邻的上一段等长时间；今天尚未结束。

输入、输出与缓存

总 Tokens = 输入 + 输出。缓存读取和缓存写入已包含在输入中，推理 Tokens 已包含在输出中，不能再次累加。缓存读取占比 = 缓存读取 / 全部输入。

额度与预测

官方账号额度独立采样。达到上限的时间以最近采样趋势估计，并限制单次跳点的影响；近期没有新增用量时不会虚构耗尽时间。预测只是使用节奏的参考，超过 15 分钟的采样标为过期，重置后需等待新采样确认。

费用与导出

优先使用日志自报费用，其余按项目内单价表估算。未知模型不会被当作免费。CSV 导出当前时间、工具和搜索筛选下的全部匹配明细，不受分页限制。

软件更新

开启自动更新后，TokenPulse 会在后台检查并下载新版本，等窗口收进托盘或最小化时静默安装并自动重启，全程不用你动手。

模型知识库

各个型号的单价、「哪些名字是同一个型号」和思考等级规则。GitHub 上每天自动从公开价格表（LiteLLM，并用 OpenRouter 交叉核对）同步一次，TokenPulse 每天自动检查并下载，新型号不用等新版本就能认出来、算出费用。各思考等级的 token 消耗参考 Epoch AI 的基准数据（CC BY 4.0）。
